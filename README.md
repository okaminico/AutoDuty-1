# AutoDuty

副本路徑自動巡覽插件：讓角色自動沿著預先規劃好的路線通過迷宮挑戰與各類
即時內容，可搭配劇情輔助器、冒險者分隊，或交給其他戰鬥插件執行戰鬥。

支援站：[Puni.sh Discord](https://discord.gg/punishxiv) 的 AutoDuty 頻道。

## 功能

- **路徑巡覽**：已支援的副本內建路線，自動移動、開啟寶箱並清怪。
- **路徑製作**：內建 `Build` 分頁可自行錄製與編輯巡覽路線。
- **自動升等**：依路徑品質、頭目支援度與等級自動挑選合適的副本循環練等，
  可搭配自動裝備最佳裝備一路全程放置練等；也可用同樣方式練等劇情輔助器
  夥伴，並自動挑選練等對象。
- **執行前**：自動移動到旅店／房屋／公會房屋、自行或委託 NPC 修理裝備、
  執行指令（例如 SND 腳本）、自動使用道具。
- **執行中**：自動拾取寶箱戰利品、依需求切換其他插件的開關狀態。
- **輪次之間**：自動抽出魔晶石、自動分解、自動繳交戰利品給公會、觸發
  AutoRetainer、自動更換最佳裝備。
- **結束條件**：達到指定等級停止、休息經驗值耗盡停止、開啟 AutoRetainer
  多帳號模式、完成後自動關機。

## 指令

- `/ad`：開啟設定視窗。

## 搭配插件

- 導航：[vnavmesh](https://github.com/ffxiv-tc-port/vnavmesh)
- 自動戰鬥：Wrath Combo 或 Rotation Solver Reborn（擇一）
- 頭目自動應對：Veyn's Boss Mod 或 BossmodReborn（擇一）
- 選用：Deliveroo（自動繳交公會物資）、Gearsetter（自動找裝備升級）、
  AutoRetainer（自動派遣雇員與潛水艇）
